## 4. Google "Near Me" Local Algorithm Blueprint

Google ranks websites for `"near me"` searches using three fundamental signals:
1. **Relevance**: How well the website content matches what the user is searching for.
2. **Distance**: How close the user's IP or GPS is to the business's physical address.
3. **Prominence**: Brand authority, reviews, structured data, and local citations.

### How Quantum Mesh Satisfies Every Signal:
1. **Physical Office Verification**:
   - Strictly positioned at: **PSA Plaza, Awas Vikas, U.S.Nagar, Rudrapur, Uttarakhand, 263153**.
   - Geo coordinates: `28.9800° N, 79.4000° E` embedded in `index.html` via `ICBM` and `geo.position` meta tags.
2. **Schema.org LocalBusiness Markup**:
   - Pre-rendered directly in the HTML `<head>` so Googlebot parses location and business hours before JavaScript hydration.
   - Explicitly declares all 13 districts of Uttarakhand in `areaServed`.
3. **Topical Authority on Root Domain**:
   - `RegionalPresenceSection.tsx` embedded on the root homepage (`https://quantummesh.com/`), transmitting local search signals from the primary domain.
4. **Dedicated Indexable Landing Pages**:
   - Direct URLs: `https://quantummesh.com/locations` and `https://quantummesh.com/locations/uttarakhand`.
   - Internal anchor links in every page's footer.
