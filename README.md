## 🛠️ Technology Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + Lucide Icons
- **Routing:** React Router v7 with dynamic meta & canonical tags
- **SEO & Discoverability:** LocalBusiness Schema.org JSON-LD, automated OpenGraph tags, dynamic XML sitemaps, and LLM search optimization (`llms.txt`, `seo-intent.json`)
- **Lead Capture & Notifications:** Google Apps Script Serverless Webhook directly syncing inquiries to Google Sheets with real-time Gmail notifications

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Yashpal568/Quantum-Mesh-Marketing-Website.git

# Navigate into directory
cd Quantum-Mesh-Marketing-Website

# Install dependencies
npm install

# Run local development server
npm run dev
```

The application will run at `http://localhost:5173`.

---

## 🚢 Production Build & Deployment

```bash
# Compile TypeScript and bundle production assets
npm run build
```

The build output will be generated in `dist/`, pre-configured for instant zero-configuration deployment to **Vercel** via `vercel.json`.
